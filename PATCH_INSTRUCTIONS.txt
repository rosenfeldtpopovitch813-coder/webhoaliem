HTVVM Studio follow-up source update

Included in this ZIP:
- ChemMaker removed from navigation, homepage, router, and source module.
- Old /chemmaker links now redirect to /exam-author (A4 Exam Authoring Studio).
- Focus Zone Pomodoro countdown now starts independently of Firebase/API.
- Offline manual/focus study time is persisted in localStorage on the current device when server tracking is unavailable.
- Existing Chemistry Handbook and Chem Arena remain.

Deploy:
1. Extract this ZIP.
2. Replace the contents of the existing GitHub repository with the extracted project files.
3. Do not upload .env files or node_modules (none are included).
4. Commit/push. Vercel should build with `npm run build` and output `dist`.
5. Check Vercel Build Logs and test /focus after deployment.

Offline local study hours stay on the same browser/device and are not automatically synced to the cloud leaderboard.
